# Thermal Express Study Guide

An interactive, steam-train-themed study guide for middle school science: thermal energy and molecular motion.

**Open it here:** https://hiflyinguy.github.io/thermal-express/

Twelve short stops, each with one idea, one thing to play with, and a question or two:
states of matter, temperature and thermal energy, heat, specific heat, changing state,
thermal expansion, conduction, convection, radiation, conductors and insulators.

It is a single self-contained page (`index.html`). Progress is saved only in the browser of whoever is using it.
